# quarto-sublime

Sublime Text plugin for [Quarto](https://quarto.org) markdown. Syntax highlighting for a wide variety of Quarto markdown constructs, including executable code cells.

# Install

+ In Sublime, add repository manually: Preferences -> Package Control -> Package Control: Add Repository, and enter: https://github.com/andreyhgl/quarto-sublime
+ Run Package Control: Preferences -> Package Control -> Package Control: Install Package, and search for quarto-sublime
+ If the original Quarto package (from the official Package Control channel) is still installed, remove it via Package Control: Remove Package to avoid the two conflicting.
